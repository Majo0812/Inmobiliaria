# Plantilla base — Sistema de gestión inmobiliaria

Esta plantilla está basada en la propuesta `PROPUESTA.pdf`.

## Archivos
- `index.html`: estructura visual de Login y módulos.
- `styles.css`: sistema visual, responsive y componentes.

## Paleta de la propuesta
Los colores se tomaron de la figura de paleta del PDF y se aproximaron a valores HEX para uso web:
- NAVY: #083B50
- GOLD: #A58D69
- AQUA: #C0D5DA
- TEAL: #427D8D
- SAND: #E5E2DD

## Módulos incluidos
1. Login
2. Dashboard
3. Pagos
4. Histórico y expedientes
5. Nuevo registro
6. Agenda
7. Estatus del inmueble
8. Usuarios (administrador)
9. Soporte

## Nota
Es una plantilla FRONT-END: los formularios, tablas y botones son visuales. Para convertirla en sistema real habrá que conectar backend, base de datos, autenticación, almacenamiento de comprobantes/expedientes, calendario y permisos.

La propuesta menciona 6 semanas de duración en las páginas 4 y posteriormente 14 semanas en la página 10; conviene aclarar esa discrepancia antes de usar el cronograma como especificación técnica.
